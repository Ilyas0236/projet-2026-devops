# Contributing Guidelines

Thank you for your interest in contributing to the Wydad Digital Platform.

## Code Standards
- **Backend (Java / Spring Boot)**: Follow standard Java conventions, format with standard 4-space indentations, and write unit/integration tests with JUnit 5.
- **Frontend (Angular / TypeScript)**: Follow Angular style guides and maintain clean component architecture with Tailwind CSS.
- **Commits**: Use Conventional Commits formatting:
  - `feat: ...` for new features
  - `fix: ...` for bug fixes
  - `docs: ...` for documentation
  - `test: ...` for tests

## Pull Request Process
1. Fork or branch from `main`.
2. Ensure your changes compile (`mvn clean test` for backend, `npm run build` for frontend).
3. Open a Pull Request referencing related issues.
