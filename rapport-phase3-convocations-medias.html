Lot 1 — Backend : convocation groupée + suivi

  • Convocation groupée POST /my-space/staff/convocations/batch : une séance, N joueurs, un seul appel. Chaque joueur est traité individuellement — doublon ou INAPTE n'annule pas les autres, il alimente la liste des rejets motivés.
  • Accusé de lecture POST /my-space/convocations/{id}/read : ownership strict (403 sinon), idempotent (re-lecture ne change pas la date).
  • Vue entraîneur GET /staff/sessions/{id}/responses + /summary : réponses présence + lecture par joueur, compteurs confirmés / absents / retards / en attente / non lus.
  • Notifications in-app automatiques pour chaque convocation créée.

Lot 2 — Backend : médias tactiques avec upload Cloudinary réel

  • Envoi multipart POST /my-space/staff/media : vidéo / photo / PDF jusqu'à 25 Mo, adressé à UN joueur (joueurUserId) ou à TOUTE la catégorie du staff (wholeTeam=true).
  • Upload réel sur Cloudinary (type authenticated) ; URL signée à la demande, valable 1 h, jamais d'URL publique permanente stockée côté joueur.
  • Ownership catégorie vérifié joueur par joueur ; l'envoi équipe est borné à la catégorie du staff.
  • Notification « Nouveau média de votre entraîneur » à chaque destinataire (best-effort).
  • Historique des envois GET /staff/media/sent avec nom de l'expéditeur résolu côté service.
  • Gestion d'erreurs dédiée : 503 si stockage indisponible, 413 si fichier trop volumineux.

Cloudinary valide les formats réels côté serveur : un faux PDF est rejeté (« Invalid PDF file ») — comportement attendu, prouvé pendant les tests E2E.

Lot 3 — Frontend staff : checklist & envoi média

  • Liste cochable des joueurs aptes (badge INAPTE visible mais non cochable), sélection « tout l'effectif », toast récapitulant créations + rejets motivés.
  • Suivi par séance : cliquer une séance du planning affiche les compteurs (confirmés / absents / en attente / non lus) et le détail par joueur avec pastille de lecture et pilule de réponse.
  • Formulaire média : fichier ≤ 25 Mo contrôlé côté client, message optionnel, ciblage UN joueur (pré-ciblage depuis le tableau de l'effectif via icône vidéo) ou toute l'équipe.
  • Sidebar « Médias envoyés » avec badges VIDEO / PHOTO / DOCUMENT et note sur les liens signés 1 h.

Lot 4 — Frontend joueur : boîte de réception unifiée

  • Mes documents enrichis : badge de type (Vidéo / Photo / Document, même code couleur que la sidebar staff), message du coach, ligne « De la part de … » avec le nom du staff, icône selon le type.
  • Accusé de lecture automatique : consulter son espace marque ses convocations non-lues (idempotent, silencieux) — le coach voit le compteur « non lu » tomber dans son suivi.
  • Pastille « Vu ✓ » verte sur les convocations lues, point rouge pulsant tant qu'elle ne l'est pas.
